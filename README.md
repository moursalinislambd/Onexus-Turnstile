Lightweight Cloudflare Turnstile protection for WordPress forms, login, registration, comments, and all major form builders.

Description
-----------

Onexus Turnstile is a lightweight plugin that adds Cloudflare Turnstile protection to your WordPress site. It's a user-friendly CAPTCHA alternative that doesn't require users to solve puzzles or identify images.

Features
--------

🔒 **Complete Form Protection** - Protects login, registration, comment, and lost password forms

🛒 **WooCommerce Support** - Works with WooCommerce login, registration, and checkout

🏗️**Page Builder Compatible** \- Works with Elementor, Contact Form 7, and other form plugins

🎨 **Customizable** \- Choose between auto, light, or dark theme and normal or compact size

⚡ **Lightweight** \- Minimal code, no jQuery dependency, loads fast

✅ **Easy Setup** \- Just add your Cloudflare Turnstile site key and secret key

🔍 **Key Validation** \- Test your keys before saving to ensure they work

🌐 **Multisite Ready** \- Works with WordPress multisite networks

How It Works
------------

Cloudflare Turnstile is a free security service that protects your site from spam and bots without requiring users to solve CAPTCHAs. It uses non-intrusive browser challenges to verify that users are human.

Installation
------------

1\. Upload the \`onexus-turnstile\` folder to the \`/wp-content/plugins/\` directory

2\. Activate the plugin through the 'Plugins' menu in WordPress

3\. Go to Settings → Onexus Turnstile

4\. Enter your Cloudflare Turnstile Site Key and Secret Key

5\. Click "Test Connection" to verify your keys

6\. Select your preferred theme and size

7\. Click "Save Settings"

Getting Cloudflare Turnstile Keys
---------------------------------

1\. Go to [https://dash.cloudflare.com/?to=/:account/turnstile](https://dash.cloudflare.com/?to=/:account/turnstile)

2\. Sign in to your Cloudflare account

3\. Click "Add a site" or create a new widget

4\. Add your website domain

5\. Copy the Site Key and Secret Key

6\. Paste them in the plugin settings

Frequently Asked Questions
--------------------------

**Is this plugin really free?**

Yes, completely free! Cloudflare Turnstile is free to use, and this plugin is also free.

**Do I need a Cloudflare account?**

Yes, you need a free Cloudflare account to get your Turnstile keys.

**Does it work with caching plugins?**

Yes, the plugin loads Turnstile asynchronously and works with all major caching plugins.

**Will it slow down my site?**

No, the plugin is extremely lightweight (under 200 lines of code) and loads Turnstile asynchronously.

**Does it work with AJAX forms?**

Yes, it works with AJAX forms including Elementor and Contact Form 7.

**Can I customize the appearance?**

Yes, you can choose between auto, light, or dark theme and normal or compact size.

**What happens if Turnstile fails?**

Users will see a friendly error message and can try again. The plugin handles errors gracefully.

**Does it work with Multisite?**

Yes, the plugin is fully compatible with WordPress Multisite networks.
